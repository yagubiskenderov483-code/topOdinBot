# Патч гифт-трекера (parswr) v3.9.0

Агент был запущен на `topOdinBot`, а живой парсер лотов — репозиторий
[`parswr`](https://github.com/yagubiskenderov483-code/parswr). Сюда положены
готовые файлы, которые нужно **скопировать поверх** одноимённых в `parswr`
и задеплоить на Bothost (`python main.py`).

Не копируйте `credentials.py` из этого PR — его здесь нет специально.

## Что починено

1. **Мало лотов (4 за пару часов)** — скан по всем коллекциям, `hot_limit=10`,
   `page_limit=20`, `parallel=8`. Раньше смотрели только 3 верхних лота
   в 45 коллекциях.
2. **Мужчины вместо девушек** — `female_only` снова включён по умолчанию.
   Имена вроде «Катя 💋» больше не пролетают мимо фильтра; «Дима» отсекается.
   В очереди выше профили без Premium и с небольшим числом NFT.
3. **Гифты / прототипы** — с маркета коллекции читаются `attributes` моделей
   (стикер прототипа + пол цены). В карточке: превью `t.me/nft/…`, строка
   «Рынок прототипа ~N⭐», стикер модели если API его отдал.

После деплоя в боте `/filters` должны гореть ✅ Девочки и ✅ Рынок.
Если файл фильтров старый — схема сама обновится до 5.
